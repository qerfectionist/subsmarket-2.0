>
> Основано на анализе поведения пользователей
> Дата: 2026-02-06

## 1. 📱 Общие принципы

### 1.1 Mobile-First

- Приложение запускается в Telegram Mini App
- Экраны оптимизированы под мобильные устройства
- Touch-friendly элементы (min 44px tap target)
- Haptic feedback на важных действиях

### 1.2 Dark Theme по умолчанию

- Соответствует Telegram Dark Mode
- Glassmorphism эффекты для карточек
- Контрастные акценты для CTA

### 1.3 Telegram Native Feel

- Bottom navigation вместо hamburger menu
- Sheet modals снизу вместо popups
- Swipe gestures где возможно

## 8. 🎨 Color System

### 8.1 Primary Palette

| Color | HEX | Usage |
| ----- | --- | ----- |
| Primary | `#6366f1` | Buttons, links, accents |
| Primary Dark | `#4f46e5` | Hover states |
| Secondary | `#22c55e` | Success, confirmations |
| Danger | `#ef4444` | Errors, delete buttons |
| Warning | `#f59e0b` | Warnings, low trust |

### 8.2 Trust Score Colors

| Score | Color | HEX |
| ----- | ----- | --- |
| 4.5-5.0 | Green | `#22c55e` |
| 3.5-4.4 | Yellow | `#eab308` |
| 2.0-3.4 | Orange | `#f97316` |
| < 2.0 | Red | `#ef4444` |

### 8.3 Background Colors

| Layer | Color | Usage |
| ----- | ----- | ----- |
| bg-primary | `#0f172a` | Main background |
| bg-secondary | `#1e293b` | Cards, sections |
| bg-input | `#334155` | Form inputs |
| bg-glass | `rgba(30, 41, 59, 0.6)` | Glassmorphism |

## 10. 🎭 Animations

### 10.1 Page Transitions

```css
.page-enter {
  opacity: 0;
  transform: translateX(20px);
}
.page-enter-active {
  opacity: 1;
  transform: translateX(0);
  transition: all 200ms ease-out;
}
```

### 10.2 Card Hover

```css
.card {
  transition: transform 150ms ease, box-shadow 150ms ease;
}
.card:active {
  transform: scale(0.98);
}
```

### 10.3 Skeleton Loading

```css
.skeleton {
  background: linear-gradient(
    90deg,
    #1e293b 25%,
    #334155 50%,
    #1e293b 75%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
}
```

## 12. ♿ Accessibility

- Minimum tap target: 44×44px
- Color contrast ratio: minimum 4.5:1
- Focus states visible
- Screen reader labels on icons
- Reduced motion option
