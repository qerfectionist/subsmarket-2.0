# 🎨 UI Health Check Workflow

Этот ворклоу предназначен для автоматической проверки интерфейса на ошибки верстки с помощью Vision-агента.

## Шаги

### 1. Запуск Frontend

Убедиться, что dev-сервер запущен (обычно `http://localhost:5173`).

### 2. Визуальный аудит страницы (Browser Subagent)

Использовать `browser_subagent` для выполнения следующих действий:

1. Перейти на целевую страницу (например, `/clubs/create`).
2. Сделать скриншот всей страницы.
3. Проверить элементы на наличие:
   - **Наложений (Overlapping)**: Текст наезжает на поля, кнопки перекрывают друг друга.
   - **Центрирования**: Элементы выровнены правильно.
   - **Contrast**: Читаемость текста на фоне.
   - **Интерактива**: Поля ввода фокусятся, выпадающие списки открываются.

### 3. Отчет об ошибках

Если найдены визуальные артефакты:

1. Зафиксировать скриншот.
2. Описать проблему (какие элементы наложились).
3. Предложить CSS-фикс.

## Пример команды для вызова под-агента
>
> "Открой <http://localhost:5173/clubs/create>, проверь форму создания клуба на наличие наложений полей 'Цена' и 'Участники'. Если видишь баги - сделай скриншот и опиши их."
