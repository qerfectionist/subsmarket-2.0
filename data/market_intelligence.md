## 2. 🎯 Pain Points (Боли пользователей)

### 2.1 Критические проблемы

| Проблема | Частота | Решение для SubsMarket |
| -------- | ------- | ---------------------- |
| **Мошенничество** | 🔴 Высокая | Trust Score + обязательная верификация через Kaspi |
| **Неплатежи участников** | 🔴 Высокая | Автоматические напоминания + история платежей |
| **Исчезновение хоста** | 🔴 Высокая | Депозит или публичный рейтинг + бан при исчезновении |
| **Региональные блокировки** | 🟡 Средняя | Фильтр по региону в UI |
| **Годовая оплата = высокий риск** | 🟡 Средняя | Рекомендации помесячной оплаты в интерфейсе |

### 2.2 UX проблемы

| Проблема | Частота | Решение для SubsMarket |
| -------- | ------- | ---------------------- |
| **Сложно найти семью** | 🔴 Высокая | Smart-matching по сервису и региону |
| **Нет истории сделок** | 🟡 Средняя | Профиль с историей + бейджи |
| **Неясные условия** | 🟡 Средняя | Стандартизированные карточки клубов |
| **Долгий поиск ответа** | 🟡 Средняя | Бейдж "Быстро отвечает" (< 1 час) |

## 4. 👥 Персоны пользователей

### 4.1 "Экономный студент" (40%)

- **Возраст:** 18-25
- **Мотивация:** Максимальная экономия
- **Поведение:** Ищет самые дешёвые варианты, готов ждать
- **Сервисы:** YouTube Premium, Spotify, Duolingo
- **Pain:** Боится кидалова, нет денег на годовую подписку

### 4.2 "Семейный хост" (25%)

- **Возраст:** 25-40
- **Мотивация:** Бесплатная подписка для себя
- **Поведение:** Создаёт семью, ищет надёжных участников
- **Сервисы:** YouTube, Netflix, Microsoft 365
- **Pain:** Неплатежи участников, административная нагрузка

### 4.3 "Tech-энтузиаст" (20%)

- **Возраст:** 20-35
- **Мотивация:** Доступ к premium-фичам
- **Поведение:** Интересуется AI (Gemini, Copilot), облаками
- **Сервисы:** Google One AI Premium, Microsoft 365, Яндекс 360
- **Pain:** Сложность шаринга AI-подписок

### 4.4 "GB-торговец" (15%)

- **Возраст:** Любой
- **Мотивация:** Монетизация излишков трафика
- **Поведение:** Продаёт GB, активен на маркетплейсе
- **Сервисы:** Алтел, Актив — продажа трафика
- **Pain:** Низкая маржа, много мелких сделок

## 6. 🛡️ Anti-Fraud рекомендации

### 6.1 Красные флаги (автобан)

- Цена значительно ниже рынка (< 50% от бенчмарка)
- Требование предоплаты до вступления в семью
- Аккаунт < 7 дней с активными объявлениями
- Множественные жалобы от разных пользователей

### 6.2 Жёлтые флаги (предупреждение)

- Годовая подписка у нового продавца
- Нет скриншота подтверждения
- Быстрая смена цен
- Неактивность > 30 дней после создания клуба

### 6.3 Рекомендованные проверки

1. **GetContact/Numbuster** — интеграция или рекомендация
2. **Kaspi verification** — проверка имени получателя
3. **Telegram Premium** — как индикатор серьёзности
4. **История в чате** — сколько сообщений, срок в группе

## 8. 📱 Telegram Bot команды

### 8.1 Рекомендованные команды

```
/start — Главное меню
/clubs — Мои семьи (как участник и хост)
/market — Маркетплейс ГБ
/search [сервис] — Поиск семьи (напр. /search youtube)
/create — Создать клуб
/sell — Создать объявление
/profile — Мой профиль и рейтинг
/help — Помощь и FAQ
/prices — Ценовой справочник
```

### 8.2 Inline-режим

```
@subsmarket_bot youtube → Карточки семей YouTube Premium
@subsmarket_bot gb алтел → Объявления продажи ГБ Алтел
@subsmarket_bot user Азамат → Профиль пользователя
```
